# Πάρκινγκ

Μικρή PWA εφαρμογή για την αποθήκευση της θέσης του αυτοκινήτου στον browser της συσκευής.

- Χειροκίνητη αποθήκευση GPS με άδεια χρήστη.
- Η παλιά θέση διατηρείται μέχρι να αποθηκευτεί νέα.
- Ημερομηνία, ώρα και ακρίβεια καταγραφής.
- Προβολή χάρτη OpenStreetMap και πλοήγηση Google Maps μόνο κατόπιν ενέργειας.
- Χωρίς Supabase ή λογαριασμό. Τα δεδομένα δεν συγχρονίζονται.
- Service worker για offline φόρτωση αφού ανοίξει επιτυχώς online.

Για δημοσίευση: Settings → Pages → Deploy from a branch → main → /(root) → Save.
